# Anto Gershan Portfolio v2

Modern cybersecurity portfolio for GitHub Pages.

## What's new
- Modern glass / SOC-inspired UI
- Responsive layout
- Animated profile stage
- Cleaner recruiter-focused typography
- Skill tiering without percentage bars
- Credential Vault with 10 uploaded certificate PDFs and thumbnails
- Credential filters: All / Security / Cloud / AI & Data
- Direct PDF and Credly verification links
- Phone remains hidden and is shown only as "available on request"

## GitHub Pages
Upload the contents of this folder to:
`antogershan24-create/anto-gershan-portfolio`

Then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

After GitHub Pages rebuilds, hard-refresh the website with Ctrl+F5.
